01. About Me

Hello! I'm Shubhankar , a full stack developer based in West Bengal, India, currently finishing my B.Tech in Computer Science. My journey into code started with a simple curiosity: I wanted to know how the websites I used every day actually worked under the hood. That curiosity turned into hundreds of hours building, breaking, and rebuilding small projects — and eventually into a career direction.

Today, I focus on building complete, production-ready web applications: a responsive React front end talking to an Express API, backed by a properly normalized MySQL or MongoDB database. I care about the details most people never see — clean commit history, sensible folder structure, and code that the next developer (often future me) can actually read.

Outside of pure development, I'm equally comfortable auditing a site's technical SEO or setting up a Google Analytics dashboard, which means I don't just build pages — I build pages that are meant to be found and used.
